# AI infrastructure research covers

Every cover identifies the research field, states a specific question or idea,
and describes what the repository provides. Exact, typeset copy leads the design;
restrained technical illustrations support it. There are no DIMAGGI names or logos.

[Design and proofreading strategy](COVER_STRATEGY.md) ·
[Authoritative portfolio workflow](PORTFOLIO.md)

The gallery covers the 13 public repositories. It is an artwork index, not a
source of portfolio membership.

**V2 active on all 13 repositories as of 2026-09-13.** Every live GitHub preview
was downloaded and verified to match its prepared JPEG byte for byte.

## Using the images

GitHub exports are 1280 × 640. Website/LinkedIn exports are 1200 × 627.
All sharing JPEGs are below 1 MB. Each repository retains the master,
original illustration, exact copy, source README commit, and generation prompt.

The Usable Compute website references its v2 LinkedIn export in its Open Graph
metadata. To replace a repository preview later, use **Social preview → Edit →
Upload an image** in the linked Settings page. Committing an image does not
replace the preview already configured in GitHub.

After updating a preview, inspect the exact shared URL with
[LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/) and check the
Featured card. Existing cards may retain cached images.
